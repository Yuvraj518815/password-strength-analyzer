# password-strength-analyzer
Password Strength Analyzer is a tool that checks a password's security by analyzing its length and character types. It rates the password as weak, moderate, or strong and helps users create safer passwords
# Password Strength Analyzer

This project checks password strength based on:
- Length
- Uppercase letters
- Numbers
- Special characters

It classifies passwords as Weak, Medium, or Strong.

Technologies Used:
- HTML
- CSS
- JavaScript
